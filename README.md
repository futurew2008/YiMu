# 译幕 YiMu

屏幕实时翻译浮层。透明、常驻顶层、鼠标穿透——把屏幕上选中的外文原文，
用译文遮挡块当场替换，像系统菜单一样无声地叠在原处。

> 译幕**完全在本机运行**：翻译走 Apple 设备端框架，零联网、零数据收集。
> 详见 [PRIVACY.md](./PRIVACY.md)。

---

## 功能特性

- **画框翻译**：圈选屏幕上任意区域，区域内文字实时替换为译文。
- **屏幕融合（全屏）**：整屏外文界面一键翻译，菜单 / 按钮 / 标签逐条覆盖。
- **指译**：按住 `⌃` 并把指针悬停在某词上，即时翻译该词。
- **偷看原文**：按住 `⇧Shift` 临时显出被遮挡的原文（用于核对）。
- **快捷键**：画框 `⌘⇧L`、屏幕融合 `⌘⇧F`、退出到菜单栏 `⌘⇧Esc`、暂停/恢复 `⌘⇧P`（均可在设置中改）。
- **离线优先**：Apple 原生离线翻译引擎，首次使用需在本机下载对应语言包（一次性，由系统完成）。

## 工作原理（为什么能"实时"）

译幕通过**辅助功能 API**读取当前前台 app 的界面文本（菜单、按钮、标签），
并对屏幕局部做**光学字符识别（OCR）**以覆盖非标准界面；文本经**设备端翻译引擎**
译出后，用一块半透明毛玻璃遮挡块盖住原文。整个过程**不截取整屏、不上传任何内容**。

## 权限说明（重要）

译幕需要你授予两项系统权限，这是它读到你屏幕内容的**唯一**途径，且全部在本地完成：

| 权限 | 用途 | 授予方式 |
|---|---|---|
| **辅助功能（Accessibility）** | 读取别家 app 的界面文本（菜单/按钮） | 系统设置 → 隐私与安全性 → 辅助功能 → 勾选「译幕」 |
| **屏幕录制（Screen Recording）** | 对屏幕局部做 OCR（画框/指译/区域） | 系统设置 → 隐私与安全性 → 屏幕录制 → 勾选「译幕」 |

打开译幕后会引导你到对应设置页。两项权限**随时可在系统设置里关掉**，关掉即停止读取。

## 安装（普通用户）

1. 到 [Releases](../../releases) 下载 `YiMu.dmg`。
2. 双击打开 dmg，把「译幕」拖到「应用程序」。
3. 首次打开若提示"无法验证开发者"，右键 → 打开（或系统设置 → 隐私与安全性 → 仍要打开）。
4. 按提示到系统设置授予「辅助功能」与「屏幕录制」权限，重启译幕即可。

> 为什么不是从 Mac App Store 安装？因为译幕依赖辅助功能 API，而 Mac App Store
> 强制的 App Sandbox 在禁用清单第一条就禁止辅助功能 API。这是苹果对所有
> "读取他窗内容"类工具（窗口管理、剪贴板历史、OCR 翻译）的统一限制，并非译幕特殊。
> 因此译幕走 **Developer ID 签名 + 苹果公证** 的官方合规分发方式，功能零改动。

## 从源码构建（开发者）

环境：macOS 15+，Swift 6（Xcode 命令行工具或 Xcode 26）。

```bash
git clone <本仓库地址> YiMu && cd YiMu
bash build-app.sh
open build/YiMu.app
```

- 默认用钥匙串里已有的「Apple Development / Developer ID」证书签名（Hardened Runtime 已启用）。
- **发布公证版**（生成已公证的 dmg）：
  ```bash
  # 方式 A：app 专用密码
  export APPLE_ID=你的AppleID
  export APPLE_APP_PASSWORD=xxxx-xxxx-xxxx-xxxx
  NOTARIZE=1 ./build-app.sh

  # 方式 B：App Store Connect API 密钥
  export APPLE_API_KEY=/绝对路径/AuthKey_XXXX.p8
  export APPLE_API_ISSUER=你的发行商ID
  NOTARIZE=1 ./build-app.sh
  ```
  凭据**只通过环境变量传入，不写进脚本、不进仓库**。生成 `build/YiMu.dmg` 即为可直接分发成品。

## 隐私

- 翻译**完全设备端**，无任何网络请求。
- 屏幕内容只在你本机处理，**绝不外传**。
- 译文缓存落盘时**只存原文 SHA-256 哈希 + 译文**，不保存原文明文。
- 开发者签名身份（Team ID、法律名）随 app 公开是代码签名的固有特性，不含你的任何信息。

完整说明见 [PRIVACY.md](./PRIVACY.md)。

## 常见问题

**Q：关掉权限后译幕还能用吗？**
A：不能读取屏幕，翻译会停止。你随时可在系统设置重新开关。

**Q：译幕会看到我所有的屏幕内容吗？**
A：只在你启用翻译时，于本机读取当前处理的文本/局部像素用于翻译，内容不外发、不留存明文。

**Q：为什么首次翻译有些词不翻？**
A：对应语言包尚未在本机下载。到 系统设置 → 通用 → 语言与地区（或系统「翻译」App）下载语言包即可，译幕会自动恢复。

**Q：支持哪些语言？**
A：取决于本机已下载的 Apple 离线语言包，常见英/中/日/韩/法/德/西/葡/俄等均可。
